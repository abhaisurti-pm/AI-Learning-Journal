This section contains practical projects created during my AI Project Management learning journey.

The objective is to move beyond theoretical learning and demonstrate how AI concepts can be translated into real product and project delivery artifacts.

The projects will progressively increase in technical and delivery complexity as new AI concepts are learned and validated.

## Project Development Framework

Each project will follow:

1. Problem Definition
2. User & Stakeholder Analysis
3. AI Opportunity Assessment
4. Business Requirements
5. Functional Requirements
6. AI Workflow
7. High-Level Architecture
8. Data & Context Requirements
9. Risks & Guardrails
10. Evaluation Framework
11. Product / Business Metrics
12. Delivery Plan
13. Implementation Considerations
14. Retrospective
15. Lessons Learned
